# API 설정 가이드

## 카카오 Geocoding API 설정

장례식장 주소를 위도, 경도로 변환하기 위해 카카오 로컬 API(Geocoding)를 사용합니다.

### ⚠️ 중요: OAuth 리다이렉트 URI는 필요 없습니다!

**현재 구현에서는 카카오 로그인 기능을 사용하지 않으므로, OAuth 리다이렉트 URI 설정이 필요하지 않습니다.**

카카오 로컬 API는 REST API 키만으로 사용할 수 있습니다. OAuth 리다이렉트 URI는 카카오 로그인 기능을 구현할 때만 필요합니다.

### 1. API 키 발급 방법

1. [Kakao Developers](https://developers.kakao.com/)에 접속
2. 로그인 후 "내 애플리케이션" 메뉴 클릭
3. "애플리케이션 추가하기" 클릭
4. 애플리케이션 정보 입력 후 저장
5. 생성된 애플리케이션의 "앱 키" → "REST API 키" 복사
6. **"제품 설정" → "로컬" 메뉴에서 로컬 API 활성화** (필수!)

### 2. 설정 파일 수정

`config/api_config.php` 파일을 열고 REST API 키를 입력하세요:

```php
define('KAKAO_REST_API_KEY', '여기에_REST_API_키_입력');
```

### 3. API 사용 제한

- 카카오 로컬 API는 무료로 제공됩니다
- 일일 요청 제한: 애플리케이션당 300,000건 (무료)
- 월 요청 제한: 9,000,000건 (무료)

### 4. 제품 설정 (중요!)

애플리케이션을 생성한 후 **반드시 다음 설정을 해야 합니다:**

1. 카카오 개발자 콘솔에서 생성한 애플리케이션 선택
2. 왼쪽 메뉴에서 "제품 설정" 클릭
3. "로컬" 제품 찾기
4. "로컬" 옆의 "활성화 설정" 버튼 클릭하여 활성화

로컬 API가 활성화되지 않으면 Geocoding API를 사용할 수 없습니다!

### 5. API 키 없이 사용

API 키가 없어도 장례식장 정보는 저장되지만, 위도/경도 값은 NULL로 저장됩니다.
API 키를 설정하지 않으려면 `config/api_config.php`에서 `KAKAO_REST_API_KEY`를 빈 문자열로 두면 됩니다.

### 6. OAuth 리다이렉트 URI란?

**현재 구현과는 무관합니다!** OAuth 리다이렉트 URI는 카카오 로그인 기능을 구현할 때 필요한 설정입니다.

- **카카오 로그인**: 사용자가 카카오 계정으로 로그인하는 기능 (OAuth 리다이렉트 URI 필요)
- **카카오 로컬 API**: 주소 검색, 좌표 변환 등의 기능 (REST API 키만 필요, OAuth 불필요)

현재는 카카오 로컬 API만 사용하므로 OAuth 리다이렉트 URI 설정을 건너뛰셔도 됩니다.
